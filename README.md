# Notification Hub 🚀

**Учебный проект: Имитатор запросов к HTTP-ручке с мониторингом (Prometheus + Grafana + Loki)**

> ⚠️ **Важно:** Проект создан с помощью ИИ (AI-assisted) в учебных целях для отработки навыков работы с асинхронным Python, очередями сообщений и стеком мониторинга.

## 📖 Описание
Проект представляет собой имитацию сервиса отправки уведомлений. Он состоит из асинхронного API на FastAPI, которое принимает запросы, складывает их в очередь Redis, а фоновый воркер разбирает эту очередь и имитирует отправку сообщений (сохраняя статус в PostgreSQL). 

Для полного цикла наблюдаемости (Observability) в проект интегрирован стек:
- **Prometheus** — сбор метрик (RPS, коды ответов, работа воркера).
- **Grafana** — визуализация графиков.
- **Loki** — централизованный сбор логов.

## 🛠 Технологии
* **Backend:** Python 3, FastAPI, SQLAlchemy (async), Pydantic.
* **База данных:** PostgreSQL 15.
* **Очередь:** Redis 7.
* **Мониторинг:** Prometheus, Grafana, Loki.
* **Инфраструктура:** Docker, Docker Compose.

## 🚀 Быстрый старт

### 1. Запуск инфраструктуры
Для запуска всех сервисов (API, воркер, БД, Redis и мониторинг) выполните:
```bash
docker compose up -d --build
```
### 2. Доступные сервисы
После запуска будут доступны:

API (Swagger): http://localhost:8000/docs

Grafana: http://localhost:3000 (Логин: admin, Пароль: admin)

Prometheus: http://localhost:9090

### 3. Импорт дашборда в Grafana
Файл с готовым дашбордом лежит в корне репозитория (grafana_dashboard.json).

Откройте Grafana (http://localhost:3000).

Перейдите в раздел Dashboards -> New -> Import.

Скопируйте содержимое grafana_dashboard.json в поле JSON и нажмите Load.

Выберите Data Source Prometheus и нажмите Import.

### Как тестировать
В репозитории есть скрипт traffic_generator.py для генерации нагрузки и ошибок.

Установите зависимости локально (если запускаете вне Docker):

```bash
pip install -r requirements.txt
```
Запустите генератор:

```bash
python traffic_generator.py
```
Генератор будет случайным образом отправлять успешные запросы (200), запросы с ошибкой валидации (422), запросы, которые упадут в воркере (FAILED), и запросы на несуществующий URL (404).

После запуска генератора перейдите в Grafana и наблюдайте за графиками:

Общая нагрузка (RPS) — покажет частоту запросов.

Коды ответов API — покажет распределение 2xx, 4xx.

Уведомления воркера — покажет успешные и упавшие отправки.

Логи (Loki) — в панели Explore можно отфильтровать логи по container="notification_hub-worker-1" и искать ошибки по trace_id.
